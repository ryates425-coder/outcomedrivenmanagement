# Contributing

## Branches

- Create a short-lived branch from `main`.
- Use names such as `content/ode-copy` or `design/homepage-cards`.
- Open a pull request and describe the outcome the change should create.

## Content review

Check that proposed changes:

- distinguish outcomes from activity;
- make assumptions explicit;
- use evidence-oriented language;
- preserve the LCO → ODM → ODE → Decision Center architecture;
- avoid presenting proposed metrics as established organizational standards.

## Quality checks

- Check desktop and mobile layouts.
- Use semantic headings.
- Test keyboard navigation.
- Preserve sufficient color contrast.
- Update documentation with material changes.
