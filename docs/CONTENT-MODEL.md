# ODM content model

## Architecture

- Philosophy: Learning-Centered Organizations
- Management system: Outcome-Driven Management
- Engineering system: Outcome-Driven Engineering
- Leadership system: Decision Center

## ODM components

1. Outcomes: what success looks like
2. Bets: what we believe
3. Evidence: what reality tells us
4. Learning Loops: how understanding improves
5. Decisions: how learning becomes action

## Core loop

Outcome → Bet → Experiment → Evidence → Decision → Adaptation → Outcome

## ODE dimensions

- Value attained
- Velocity achieved
- Quality delivered
- Trust earned
