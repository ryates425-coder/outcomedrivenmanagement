## Implementation notes

- Recreate the structural layout with Squarespace Fluid Engine where practical.
- Use Squarespace text and button blocks for editable content.
- Use a Code Block for the architecture stack or ODM loop if the native layout is insufficient.
- Adapt relevant declarations from `styles.css` in Squarespace Custom CSS.
- Do not paste a complete document with `<html>`, `<head>`, or `<body>` tags into a single Code Block.

## Launch checklist

- Replace placeholder contact details.
- Set the final navigation links.
- Configure site title, favicon, SEO title, description, and social sharing image.
- Review desktop, tablet, and mobile layouts.
- Add required privacy, accessibility, analytics, and cookie content.
- Source-vet public historical claims.
